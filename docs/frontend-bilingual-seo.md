# BG/EN — съдържание и SEO

Дата: 10 октомври 2026 г.

## Приоритети и резултат

| Приоритет | Проверка | Резултат |
| --- | --- | --- |
| P0 | HTML, който живият сървър връща за подстраница | Изисква корекция в хостинга. `/en/services` връща HTTP 200, общ български title, без H1 и canonical в първоначалния HTML. Английското съдържание се появява след JavaScript. |
| P1 | Действително английско съдържание | Поправени определянето на езика на услугите, FAQ, сравнението, резервацията, фирмената информация, категориите, описанията на изображенията и полетата във формите. |

Изходният sitemap вече съдържа страниците за ваучери и информация за студиото на двата езика. Проверена е генерацията им, без промяна на URL-ите. Регионалните български SEO landing pages запазват адресите си. Английските регионални връзки от началната страница водят към английската страница с двете локации.

## Проверки

- Чист production build генерира 103 реални страници; неканоничният alias се изключва от build sitemap. Генериран е и отделен noindex документ за 404.
- `npm run type-check` и `npm run lint` минават.
- `npm test`: 10/10. Новите проверки обхождат английския HTML, достъпните описания, езиковите метаданни, реципрочността и каноничността на hreflang, езика на схемите и продуктовите URL-и. Съществуващите проверки на резервациите и защитата срещу изпълним HTML остават успешни.
- Цветовете, CSS темата, логото, изображенията и Supabase модулът не са променяни. Няма промени в база, политики, функции или реални резервации. Използвани са само публични SELECT заявки за блога при build и mock заявки в тестовете.

## Необходима корекция в хостинга

Сървърът трябва първо да обслужва съществуващия `out/<route>/index.html`, а след това да прилага SPA fallback. Publish директорията трябва да съдържа целия `out`, включително подпапките и обработения sitemap. Непознатите URL-и трябва да връщат HTTP 404 с подходящия документ.

В репото няма конфигурация или свързан достъп до текущия хостинг. Не е добавяна конфигурация за предполагаем доставчик. След корекцията е нужна нова директна HTTP проверка на `/`, `/en`, BG/EN услуга, BG/EN статия и несъществуващ URL. JavaScript трябва да е изключен за тази проверка.

Техническата готовност на двата езика не измерва позициите в Google. За ефекта върху търсенията „масаж Велико Търново“, „масажи Велико Търново“ и „massage Veliko Tarnovo“ са нужни данни от Search Console по заявка и URL след преобхождане. Първо място не се гарантира с техническа промяна.
